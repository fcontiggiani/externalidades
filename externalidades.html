Permite contrastar instrumentos de internalización bajo competencia perfecta o con poder de mercado del vendedor, del comprador o de ambos.

Externalidades presentes

Los efectos se agregan: BMgS = BMgP − Σ(efectos de consumo) y CMgS = CMgP + Σ(efectos de producción), con costos sumando y beneficios restando.

Mercado del bien (curvas privadas)

BMgP(Q) = a − bQ (demanda)  ·  CMgP(Q) = c + dQ (oferta).

Estructura de mercado

La cantidad surge del lado corto, Q = mín{Qmonopolio, Qmonopsonio}; el precio se ubica entre CMgP(Q) (β = 0) y BMgP(Q) (β = 1).

Medida de internalización

Lectura económica

Modelo lineal con fines ilustrativos: BMgP(Q) = a − bQ, CMgP(Q) = c + dQ, EMgk(Q) = ek (constante) o gk·Q (creciente) para cada externalidad k, agregadas con signo en X(Q) = Σ sk·EMgk(Q). Bienestar social W = EC + EP + fisco + rentas ± efecto externo = ∫0Q[BMgS(q) − CMgS(q)]dq; las transferencias (impuestos, subsidios, pagos de Coase) son redistribuciones que no alteran W. PIE = Wmáx − W. Archivo autocontenido (HTML + JavaScript + SVG), sin dependencias externas.
